## 统计方法说明

1. **grep搜索**：使用正则表达式匹配关键字
2. **去重处理**：同一行多次出现计为一次
3. **文件统计**：统计包含关键字的文件数量
4. **抽样验证**：随机检查部分结果准确性
5. **模式分析**：结合代码结构理解统计意义

## 数据局限性

1. **重复计数**：同一特性在头文件和实现文件可能重复统计
2. **宏影响**：宏定义可能干扰关键字统计
3. **模板展开**：模板实例化未单独统计
4. **注释代码**：注释中的关键字未被过滤
5. **字符串字面量**：字符串中的关键字可能被误统计
